# Bibliografía y enlaces de interés

La documentación que hay detrás de esta sesión, sacada del deck de la sesión.
Las páginas de Unity van por versiones, así que cada entrada dice a cuál apunta
y cuándo se consultó.

## XR Interaction Toolkit

- [XR Interaction Toolkit 3.1](https://docs.unity3d.com/Packages/com.unity.xr.interaction.toolkit@3.1/index.html), Unity Technologies · 15/11/2026
  La página de inicio del propio paquete: qué es, qué necesita y qué hace.
- [Samples (XR Interaction Toolkit 3.0)](https://docs.unity3d.com/Packages/com.unity.xr.interaction.toolkit@3.0/manual/samples.html), Unity Technologies · 15/11/2026
  Los Starter Assets y los demás samples, y cómo importarlos desde el Package Manager.
- [XR Interaction Toolkit Examples](https://github.com/Unity-Technologies/XR-Interaction-Toolkit-Examples), Unity Technologies en GitHub · 15/11/2026
  Las escenas de ejemplo que lista el deck: sockets, puerta, cajón, palanca, rueda, grúa, botones de UI, sliders, dropdowns, toggles, teleportación, agarre, movimiento físico, steering, knob, cañón de confeti, gaze.

## OpenXR

- [OpenXR Plugin 1.14](https://docs.unity3d.com/Packages/com.unity.xr.openxr@1.14/index.html), Unity Technologies · 15/11/2026
- [OpenXR Plugin: manual](https://docs.unity3d.com/Packages/com.unity.xr.openxr@1.14/manual/index.html), Unity Technologies · 15/11/2026
  La tabla de plataformas soportadas, que es la diapositiva de la fragmentación en forma de referencia.

## La plantilla VR

- [VR Template Quick Start Guide 9.1](https://docs.unity3d.com/Packages/com.unity.template.vr@9.1/manual/index.html), Unity Technologies · 15/11/2026
  La plantilla de la que arranca el proyecto, y qué viene dentro.
- [Create an XR project (manual de Unity 6000.1)](https://docs.unity3d.com/6000.1/Documentation/Manual/xr-create-projects.html), Unity Technologies · 15/11/2026
  Los paquetes que necesita un proyecto de VR, y cuáles instala la plantilla por vosotros.

## Citados en el deck, sin enlace
