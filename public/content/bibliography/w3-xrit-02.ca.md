# Bibliografia i enllaços d'interès

La documentació que hi ha darrere d'aquesta sessió, treta del deck de la
sessió. Les pàgines d'Unity van per versions, així que cada entrada diu a
quina apunta i quan es va consultar.

## XR Interaction Toolkit

- [XR Interaction Toolkit 3.1](https://docs.unity3d.com/Packages/com.unity.xr.interaction.toolkit@3.1/index.html), Unity Technologies · 15/11/2026
  La pàgina d'inici del mateix paquet: què és, què necessita i què fa.
- [Samples (XR Interaction Toolkit 3.0)](https://docs.unity3d.com/Packages/com.unity.xr.interaction.toolkit@3.0/manual/samples.html), Unity Technologies · 15/11/2026
  Els Starter Assets i la resta de samples, i com importar-los des del Package Manager.
- [XR Interaction Toolkit Examples](https://github.com/Unity-Technologies/XR-Interaction-Toolkit-Examples), Unity Technologies a GitHub · 15/11/2026
  Les escenes d'exemple que llista el deck: sockets, porta, calaix, palanca, roda, grua, botons d'UI, sliders, dropdowns, toggles, teleportació, agafada, moviment físic, steering, knob, canó de confeti, gaze.

## OpenXR

- [OpenXR Plugin 1.14](https://docs.unity3d.com/Packages/com.unity.xr.openxr@1.14/index.html), Unity Technologies · 15/11/2026
- [OpenXR Plugin: manual](https://docs.unity3d.com/Packages/com.unity.xr.openxr@1.14/manual/index.html), Unity Technologies · 15/11/2026
  La taula de plataformes suportades, que és la diapositiva de la fragmentació en forma de referència.

## La plantilla VR

- [VR Template Quick Start Guide 9.1](https://docs.unity3d.com/Packages/com.unity.template.vr@9.1/manual/index.html), Unity Technologies · 15/11/2026
  La plantilla de la qual arrenca el projecte, i què hi ha a dins.
- [Create an XR project (manual d'Unity 6000.1)](https://docs.unity3d.com/6000.1/Documentation/Manual/xr-create-projects.html), Unity Technologies · 15/11/2026
  Els paquets que necessita un projecte de VR, i quins instal·la la plantilla per vosaltres.

## Citats al deck, sense enllaç

Val la pena saber-se'n els noms; el deck els ensenya però no els enllaça.

- **XR Device Simulator**, per moure una escena sense posar-se el visor.
- **SideQuest** i **Meta Quest Developer Hub**, les dues maneres de portar la vista del visor a la pantalla del PC.
