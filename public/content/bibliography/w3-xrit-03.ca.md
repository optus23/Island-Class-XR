# Bibliografia i enllaços d'interès

La documentació que hi ha darrere d'aquesta sessió, treta del deck de la
sessió. Les pàgines d'Unity van per versions: les marcades com a *latest*
obren sempre la versió actual, i cada entrada diu quan es va consultar.

## La plantilla Mixed Reality

- [Mixed Reality Template Quick Start Guide 1.0](https://docs.unity3d.com/Packages/com.unity.template.mixed-reality@1.0/manual/index.html), Unity Technologies · 18/11/2026
  La plantilla de la qual arrenca el projecte, què porta i els seus límits: el Space Setup s'ha de fer abans al visor, només es classifiquen superfícies horitzontals mirant amunt, i la detecció de plans i el passthrough només funcionen en una build, no donant a Play.

## Els paquets sobre els quals està feta la plantilla

- [OpenXR Plugin (latest)](https://docs.unity3d.com/Packages/com.unity.xr.openxr@latest/index.html), Unity Technologies · 18/11/2026
- [AR Foundation (latest)](https://docs.unity3d.com/Packages/com.unity.xr.arfoundation@latest/index.html), Unity Technologies · 18/11/2026
- [XR Interaction Toolkit (latest)](https://docs.unity3d.com/Packages/com.unity.xr.interaction.toolkit@latest/index.html), Unity Technologies · 18/11/2026

## Exemples

- [XR Interaction Toolkit Examples](https://github.com/Unity-Technologies/XR-Interaction-Toolkit-Examples), Unity Technologies a GitHub · 18/11/2026
  D'on surten les funcionalitats extra, inclosos els socket interactors de l'exemple de l'inventari (`XRI_Examples > SocketInteractors > Prefabs > Simple Socket`).

## Citats al deck, sense enllaç

Val la pena saber-se'n els noms; el deck els ensenya però no els enllaça.

- **XR Hands**, el paquet que afegeix el hand tracking (`com.unity.xr.hands`, s'afegeix per nom des del Package Manager), amb els seus samples **HandVisualizer** i **Hand Interaction Demo**.
- **Hand Tracking with Unity XR Interaction Toolkit**, un vídeo tutorial de Valem Tutorials a YouTube, incrustat al deck.
