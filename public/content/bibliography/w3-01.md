# Bibliography and further reading

The official documentation for every topic on the session deck, *Unity
Introduction*. The deck itself links nothing, so each entry below is the page
that explains that slide in full. Unity's manual pages open the current
version of the editor, and each entry says when it was read.

## The Unity editor

- [Introduction to assets in Unity](https://docs.unity3d.com/Manual/AssetWorkflow.html), Unity Technologies · 22/11/2026
  Everything a project is made of: models, 2D art, audio, scripts, shaders, materials, scenes and prefabs.
- [Introduction to scenes](https://docs.unity3d.com/Manual/CreatingScenes.html), Unity Technologies · 22/11/2026
- [Manage GameObjects in the Hierarchy window](https://docs.unity3d.com/Manual/Hierarchy.html), Unity Technologies · 22/11/2026
  Includes how parenting works: a child moves, rotates and scales with its parent.
- [Introduction to GameObjects](https://docs.unity3d.com/Manual/GameObjects.html), Unity Technologies · 22/11/2026
- [Inspector window reference](https://docs.unity3d.com/Manual/UsingTheInspector.html), Unity Technologies · 22/11/2026
- [Prefabs](https://docs.unity3d.com/Manual/Prefabs.html), Unity Technologies · 22/11/2026
- [Assign tags to GameObjects](https://docs.unity3d.com/Manual/Tags.html), Unity Technologies · 22/11/2026
  The "Add tag" step of the exercise.

## Physics: what the exercise needs

- [Introduction to collision](https://docs.unity3d.com/Manual/CollidersOverview.html), Unity Technologies · 22/11/2026
  Colliders, and the difference between a collision and a trigger.
- [Rigidbody component reference](https://docs.unity3d.com/Manual/class-Rigidbody.html), Unity Technologies · 22/11/2026
  Why the "player" object needs one: without a Rigidbody, nothing reports a collision.
- [OnCollisionEnter(Collision)](https://docs.unity3d.com/ScriptReference/Collider.OnCollisionEnter.html) and [OnTriggerEnter(Collider)](https://docs.unity3d.com/ScriptReference/Collider.OnTriggerEnter.html), Unity Scripting API · 22/11/2026

## C# in Unity

- [Create scripts](https://docs.unity3d.com/Manual/CreatingAndUsingScripts.html), Unity Technologies · 22/11/2026
- [MonoBehaviour](https://docs.unity3d.com/ScriptReference/MonoBehaviour.html), Unity Scripting API · 22/11/2026
  Every script you create in Assets is a class inheriting from it, which is where `Start` and `Update` come from.
- [Built-in types](https://learn.microsoft.com/en-us/dotnet/csharp/language-reference/builtin-types/built-in-types), Microsoft Learn · 22/11/2026
  `bool`, `int`, `float`, `string` and the rest.
- [Selection statements: if, else and switch](https://learn.microsoft.com/en-us/dotnet/csharp/language-reference/statements/selection-statements), Microsoft Learn · 22/11/2026
- [Iteration statements: for, foreach, do and while](https://learn.microsoft.com/en-us/dotnet/csharp/language-reference/statements/iteration-statements), Microsoft Learn · 22/11/2026
- [Methods](https://learn.microsoft.com/en-us/dotnet/csharp/programming-guide/classes-and-structs/methods), Microsoft Learn · 22/11/2026
- [Classes](https://learn.microsoft.com/en-us/dotnet/csharp/fundamentals/types/classes), Microsoft Learn · 22/11/2026
