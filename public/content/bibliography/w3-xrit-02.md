# Bibliography and further reading

The documentation behind this session, taken from the session deck. Unity's
pages are versioned, so each entry says which version it points at and when it
was read.

## XR Interaction Toolkit

- [XR Interaction Toolkit 3.1](https://docs.unity3d.com/Packages/com.unity.xr.interaction.toolkit@3.1/index.html), Unity Technologies · 15/11/2026
  The package's own home page: what it is, what it needs, what it does.
- [Samples (XR Interaction Toolkit 3.0)](https://docs.unity3d.com/Packages/com.unity.xr.interaction.toolkit@3.0/manual/samples.html), Unity Technologies · 15/11/2026
  The Starter Assets and the other samples, and how to import them from the Package Manager.
- [XR Interaction Toolkit Examples](https://github.com/Unity-Technologies/XR-Interaction-Toolkit-Examples), Unity Technologies on GitHub · 15/11/2026
  The example scenes the deck lists: sockets, door, drawer, lever, wheel, crane, UI buttons, sliders, dropdowns, toggles, teleportation, grabbing, physical motion, steering, knob, confetti gun, gaze.

## OpenXR

- [OpenXR Plugin 1.14](https://docs.unity3d.com/Packages/com.unity.xr.openxr@1.14/index.html), Unity Technologies · 15/11/2026
- [OpenXR Plugin: manual](https://docs.unity3d.com/Packages/com.unity.xr.openxr@1.14/manual/index.html), Unity Technologies · 15/11/2026
  The supported platforms table, which is the slide on fragmentation in reference form.

## The VR template

- [VR Template Quick Start Guide 9.1](https://docs.unity3d.com/Packages/com.unity.template.vr@9.1/manual/index.html), Unity Technologies · 15/11/2026
  The template the project starts from, and what comes inside it.
- [Create an XR project (Unity 6000.1 manual)](https://docs.unity3d.com/6000.1/Documentation/Manual/xr-create-projects.html), Unity Technologies · 15/11/2026
  The packages a VR project needs, and which the template installs for you.

## Named on the deck, without a link

Worth knowing the names; the deck shows them rather than linking them.

- **XR Device Simulator**, for driving a scene without the headset on.
- **SideQuest** and **Meta Quest Developer Hub**, the two ways of casting the headset's view onto the PC screen.

## Secondary, and not Unity documentation

- [Make VR more immersive with nothing but air](https://medium.com/vrdojo/make-vr-more-immersive-with-nothing-but-air-910d419c04f2), Michael Eichenseer, VRdojo on Medium · 15/11/2026
  An opinion piece from 2017 on headset-mounted fans and airflow as a way of increasing immersion. It is about hardware comfort, not about the toolkit, so read it as background on immersion rather than as a source for anything in this session.
