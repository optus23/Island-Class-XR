# Bibliografía y enlaces de interés

La documentación oficial de cada tema del deck de la sesión, *Unity
Introduction*. El deck no enlaza nada, así que cada entrada es la página que
explica esa diapositiva a fondo. El manual de Unity abre siempre la versión
actual del editor, y cada entrada dice cuándo se consultó.

## El editor de Unity

- [Introduction to assets in Unity](https://docs.unity3d.com/Manual/AssetWorkflow.html), Unity Technologies · 22/11/2026
  Todo aquello de lo que está hecho un proyecto: modelos, arte 2D, audio, scripts, shaders, materiales, escenas y prefabs.
- [Introduction to scenes](https://docs.unity3d.com/Manual/CreatingScenes.html), Unity Technologies · 22/11/2026
- [Manage GameObjects in the Hierarchy window](https://docs.unity3d.com/Manual/Hierarchy.html), Unity Technologies · 22/11/2026
  Incluye cómo funciona el parenting: un hijo se mueve, gira y escala con su padre.
- [Introduction to GameObjects](https://docs.unity3d.com/Manual/GameObjects.html), Unity Technologies · 22/11/2026
- [Inspector window reference](https://docs.unity3d.com/Manual/UsingTheInspector.html), Unity Technologies · 22/11/2026
- [Prefabs](https://docs.unity3d.com/Manual/Prefabs.html), Unity Technologies · 22/11/2026
- [Assign tags to GameObjects](https://docs.unity3d.com/Manual/Tags.html), Unity Technologies · 22/11/2026
  El paso "Add tag" del ejercicio.

## Física: lo que necesita el ejercicio

- [Introduction to collision](https://docs.unity3d.com/Manual/CollidersOverview.html), Unity Technologies · 22/11/2026
  Los colliders, y la diferencia entre una colisión y un trigger.
- [Rigidbody component reference](https://docs.unity3d.com/Manual/class-Rigidbody.html), Unity Technologies · 22/11/2026
  Por qué el objeto "player" necesita uno: sin Rigidbody, nadie avisa de una colisión.
- [OnCollisionEnter(Collision)](https://docs.unity3d.com/ScriptReference/Collider.OnCollisionEnter.html) y [OnTriggerEnter(Collider)](https://docs.unity3d.com/ScriptReference/Collider.OnTriggerEnter.html), Unity Scripting API · 22/11/2026
